# EfficientNet-Fine-Tuning-Edge-Deployment-Pipeline
Industrial visual inspection systems require accurate, fast, and resource-efficient models for deployment on edge devices. This project demonstrates a complete pipeline from data manipulation, model architecture, fine-tuning a pre-trained EfficientNet on domain-specific data to INT8-quantized ONNX deployment, achieving better inference latency and accuracy, and deployment on equipment.

## Goal
last CNN journey, the pipeline of CV project is constructued, but that project is for learning the pipeline and some basic tools. this project gonna use the pipeline, but in much simple way. In this project, the data is checked, and manipulated for training. the model architecture and training  strategy is selected, compression strategy and deployment decision are made.
